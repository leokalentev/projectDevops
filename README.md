# Поиск мероприятий для студентов Казанксого Федерального Университета (КФУ)

В современных университетах внеучебная активность играет ключевую роль в развитии студентов. Однако информация о мероприятиях зачастую разрозненна и труднодоступна. Этот проект — прототип web-приложения, упрощающего поиск, просмотр и создание студенческих мероприятий в Казанском (Приволжском) федеральном университете (КФУ).

---

## 🚀 Возможности

- Регистрация и аутентификация пользователей;
- Поиск мероприятия по категориям, статусам, названиям и датам;
- Просматривать подробности событий;
- Создавать, редактировать и удалять собственные мероприятия.


---

## Функциональность
- Регистрация и аутентификация пользователей (JWT)
- CRUD-операции с мероприятиями
- Разграничение прав доступа (только автор может редактировать/удалять свои события)
- Фильтрация и поиск мероприятий по категориям и статусам
- Управление справочниками (категории, статусы)
- Защита API и валидация входящих данных
- Разделение клиентской и серверной логики
- Полностью реализованная клиентская часть на HTML, CSS и JavaScript (без фреймворков)

## Архитектура:
- **Модель: сущности спроектированы с учетом связей (OneToMany, ManyToMany)**
- **Контроллеры: реализуют стандартные REST-эндпоинты для пользователей, мероприятий, категорий и статусов**
- **DTO и мапперы: обеспечивают чистую архитектуру и абстрагирование от внутренней логики**
- **JWT: используется для защиты API и проверки прав доступа**
- **Валидация: встроена на уровне DTO и контроллеров**

## 🚴‍♂️ Как запустить

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/leokalentev/cursovay.git
   cd cursovay/app

2. **Создайте БД и укажите параметры подключения:**
   ```bash
   spring:
     datasource:
      url: jdbc:postgresql://localhost:5432/task_manager
      username: postgres
      password: your_password

3. **Запустите миграции:**
   ```bash
   ./gradlew flywayMigrate

4. **Запуск приложения:**
   ```bash
   ./gradlew bootRun
